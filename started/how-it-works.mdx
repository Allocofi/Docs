## Security Notice

All official Alloco websites use the **allocofi.com** domain.

Alloco team members will never:

- Ask for your private key or seed phrase
- Request that you transfer assets to a personal wallet
- Contact you first through an unofficial account
- Ask you to install unknown software or browser extensions

Smart contract addresses and supported network details will only be published in the official documentation.

<Warning>
  Always verify the domain and contract address before connecting your wallet or signing a transaction.
</Warning>
